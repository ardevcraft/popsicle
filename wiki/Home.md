# Popsicle Wiki

Popsicle is built around a small idea:

```text
UI = f(state)
```

The 2.1 API adds `commit(...)`, `.ui()`, opt-in history, and Store-owned streams while keeping the same `Popsicle.*` and `Scope` model.
